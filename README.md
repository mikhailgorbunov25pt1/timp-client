# Программная реализация сетевого клиента

Курсовая работа по дисциплине «Технологии и методы программирования», вариант 25.
Клиент читает векторы uint16_t из текстового файла, проходит аутентификацию
на сервере (SHA-224, соль формирует клиент), передает векторы и сохраняет
результаты в текстовый файл.

## Зависимости

```
sudo apt install g++ make libboost-program-options-dev libcrypto++-dev
```

## Сборка и запуск

```
make
./client -a 127.0.0.1 -i data.txt -o result.txt -c vclient.conf
```

Файл учетных данных содержит строку `LOGIN:PASSWORD`.
